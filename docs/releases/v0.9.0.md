# Quillan v0.9.0

Status: release candidate; not yet published or owner-authorized.

Quillan v0.9.0 gives the Core 0.6 academic-publication implementation completed
across #356 through #365 a unique distribution identity. It requires
`pds-core>=0.6,<0.7` and qualifies against the exact released Core 0.6.0 wheel.

The release adds explicit Academic Work Registration, immutable privacy-safe
Academic Result Manifest v1 generation, the publication producer profile, Core
publication/supersession/withdrawal/republication, a consumer-neutral public
reader, separately authorized artifacts, and installed end-to-end producer
acceptance.

The existing PDS2 routing boundary and producer contracts do not change. Native
writing/review/rating/non-score meanings are preserved; Quillan adds no Grade,
proficiency, attempt-selection, or portfolio policy and no sibling dependency.

Final commit, artifact sizes/hashes, CI evidence, visual result, physical result,
release date, and authorization will be recorded only after those events occur.
See the [compatibility contract](../v0.9.0_release_compatibility.md),
[acceptance matrix](v0.9.0_acceptance_matrix.md), and
[physical checklist](../physical_acceptance_v0.9.0.md).
