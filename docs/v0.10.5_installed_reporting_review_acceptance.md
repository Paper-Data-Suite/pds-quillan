## Installed program

`scripts/verify_installed_issue417_acceptance.py` runs from a directory outside
the source checkout and requires exact installed Quillan/Core versions.

The synthetic workspace includes:

- one assignment with one Focus Standard;
- a configurable three-level rating scale;
- an accented student name (`Zoë Álvarez`);
- a Unicode standard label containing an em dash;
- one teacher-confirmed overall rating;
- a private teacher note and private rating rationale that must not leak;
- one rostered student with no submission so missing state remains visible.

## Reporting assertions

One call to the installed assignment-reporting packet service must create:

```text
student_performance_summary.csv
class_summary.csv
standards_summary.csv
assignment_review_report.pdf
assignment_results_manifest.json
```

The acceptance verifies:

- exactly those five new derived files are created;
- every pre-existing canonical workspace file is byte-identical afterward;
- all three CSVs start with exactly one UTF-8 BOM;
- BOM-aware text has no logical `\ufeff` header;
- `Zoë Álvarez` and `W.REPORT.1 — Evidence — Integration` round-trip exactly;
- known mojibake markers are absent;
- the PDF is readable through PyPDF and carries assignment/report identity;
- the JSON has record type `assignment_results_manifest`;
- the JSON artifact inventory sees the three CSVs and PDF as present and itself
  as generated;
- private teacher notes, rating rationale, and assignment prompt are absent from
  all report formats.

## Navigation assertions

The installed review menu must:

- contain no visible numbered `Back` entry;
- contain no hand-copied `print("B. Back")` path that bypasses the shared
  navigation printer;
- render the canonical shared controls:

```text
B. Back
M. Main Menu
Q. Quit
```

- treat `B` as safe local return/cancel;
- propagate `M` through `ReturnToMainMenu`;
- propagate `Q` through `QuitQuillan`.

Source-level tests separately cover successful terminal-stage unwind and fresh
`Continue Review` recalculation.

## Physical acceptance

scan intake, or image/PDF evidence decoding. No new owner-operated physical
paper acceptance is required for v0.10.5.

The historical v0.10.4 #416 deep-path scan acceptance is rerun against released
Core 0.6.4 as a regression gate because release qualification already exercises
that boundary.
