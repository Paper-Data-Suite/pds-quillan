Issue #366 assigns the unique distribution identity `quillan==0.9.0` to the
Core 0.6 academic-publication work completed by #356 through #365. Historical
v0.8.9 remains the Core 0.5 PDS2 release.

## Frozen routing and publication contracts

Routing remains module `quillan`, Core contract `1`, QR schema `PDS2`, route
registration schema `1`, and dispatchable status `active`. Its entry point is
`quillan = quillan.pds_module:get_module_profile` in
`paper_data_suite.modules`.

Publication remains:

```text
entry-point group: paper_data_suite.publication_producers
entry point: quillan = quillan.pds_publication:get_publication_producer_profile
producer module: quillan
publication kind: academic_result_set
Academic Work contract: quillan_academic_work_v1
manifest contract: quillan_academic_result_manifest_v1
record set: academic_results
source record: absent
capabilities: standards_ratings
```

Academic Work Registration stays explicit, Core-owned, revisioned, independent
of manifest revision and publication identity, and absent from ordinary Quillan
workflows. Manifests stay immutable below
`exports/manifests/academic_results/<revision>.json`; there is no mutable latest
or current alias.

## Reader and artifact boundaries

The wheel ships `quillan.academic_result_reader`. It accepts canonical immutable
bytes, returns immutable producer-owned models, performs no filesystem or Core
catalog access, and selects no latest, best, or official result. The artifact
resolver supports only `student_work`, `feedback_pdf`, and `feedback_markdown`.
Authorization occurs before workspace or artifact existence probing.

Historical manifest validity is distinct from mutable artifact availability.
Feedback whose native review state drifted fails closed; unchanged exact selected
PDS2 student work may remain resolvable.

## Native semantics, privacy, and consumer neutrality

Assignment-local scale values are exact: a native rating `1` remains `1`, while
a missing rating remains absent/not found. `not applicable`, missing evidence,
and `returned_without_full_review` are not converted to zero or failure.

The public projection excludes private notes, retained/routed private paths,
raw QR values, candidate/duplicate/excluded evidence, reusable-comment provenance,
and absolute/workspace paths. `PublishedText` remains exactly `absent`, `withheld`,
or `included`; withheld content is not copied elsewhere.

Quillan calculates no course Grade, assignment percentage, cross-assignment
proficiency/mastery, attempt selection, or portfolio eligibility/ranking.

## Downstream handoff and sibling isolation

Meridian issue #10 can bind exactly to distribution `quillan`, version `0.9.0`,
reader `quillan.academic_result_reader`, and the producer identity above.
Meridian continues to own evidence projection, eligibility, Grade-item membership,
attempt/reassessment policy, proficiency mapping, Academic Period policy, Grade
calculation, and reporting. Quillan has no Meridian dependency or policy.

No live Vitrine support is claimed. Quillan creates no Candidate, Portfolio
Subject, portfolio eligibility/ranking/selection/placement, Snapshot, or disclosure
policy. Artifact availability is not portfolio eligibility.

Quillan has no runtime dependency on or production import from Meridian, Vitrine,
ScoreForm, Concord, or Portia. Its wheel and sdist bundle neither sibling nor Core
source.

## Release gates

Pre-merge qualification produces reviewable evidence but grants no authority.
After merge, exact final `main` must be rebuilt and requalified; the owner must
complete physical acceptance and explicitly authorize the exact commit and hashes.
Only then may `v0.9.0` and the GitHub Release be created. Downloaded release assets
must then pass clean-install and producer-lifecycle verification. No package index
publication is part of this release.
