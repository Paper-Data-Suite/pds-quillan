# v0.10.3 Installed Resubmission Inbox Acceptance

This is the active installed-wheel acceptance contract for Quillan 0.10.3.
`scripts/verify_installed_resubmission_inbox.py` runs outside the source checkout
against the exact candidate wheel under authenticated PDS Core 0.6.2 and 0.6.3
environments.

The synthetic workflow creates one rostered student and assignment plus an
issued printable-response identity. It executes the real submission assembly
service for the initial immutable response-page observation, generates real PDF
and Markdown feedback through `export_student_feedback_pdf`, creates a distinct
later physical-intake observation whose evidence bytes intentionally match the
first scan, and executes assembly again. It then verifies:

- both observations and routed evidence pass strict path, hash, size, and
  retained-provenance validation;
- feedback remains current while the later observation awaits assembly and
  after it is assembled as a candidate;
- the later observation appears as `new after feedback`;
- the original and candidate open only through the fresh exact-evidence service,
  including action-time hash and provenance verification;
- explicit candidate selection retains both observations and evidence records;
- a fresh inbox rebuild has no unresolved newer evidence;
- feedback generated before the selected-evidence change reports stale;
- installed imports originate outside the source repository.

The validator builds the wheel/sdist pair once and runs this acceptance against
the same wheel bytes at both Core endpoints. Artifact filenames, lengths, and
SHA-256 hashes are recorded before release authorization. Passing this check does
not authorize a tag, GitHub Release, package-index upload, or deployment.

Issue #415 does not alter QR generation, page identity, scan intake, Core
routing, retained-source creation, routed-evidence persistence, or physical-page
interpretation. The historical v0.10.0 physical acceptance therefore remains
applicable unless the implementation diff crosses one of those boundaries.
